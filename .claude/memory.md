## 2026-08-02 — Setup 3 écrans
L'utilisateur travaille avec une configuration à 3 écrans (bureau virtuel Windows multi-moniteurs). Toute fonctionnalité de sélection ou de capture à l'écran (ex : overlay de sélection de zone) doit couvrir tout le bureau virtuel, pas seulement l'écran principal — les API type `-fullscreen` Tk ne couvrent qu'un seul écran et sont insuffisantes.
